# Quick Reset & Hold Checkpoints (Geode)

- **R** — мгновенно начинает новую попытку (сбрасывает уровень с начала или с последнего чекпоинта в зависимости от настроек).
- **Z в practice-режиме** — удерживайте Z, чтобы автоматически ставить чекпоинты с заданным интервалом.

Настройки мода доступны в меню Geode.

## Сборка
GitHub → Actions → Build Geode Mod → запустите workflow вручную или отправьте push. Готовые сборки публикуются в артефакте **Build Output**.
